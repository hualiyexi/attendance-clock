# attendance-clock · 打卡倒计时

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一个 [DeepSeek Harness (DSH)](https://github.com/deepseek-ai) 插件：在 Web 界面消息输入框底部常驻一行极简打卡状态芯片。

![icon](icon.svg)

## 功能

芯片仍然只显示一条主信息，但会随当前阶段变化：

| 时机 | 芯片显示 | 可执行操作 |
|---|---|---|
| 上班前、未打卡 | 上班倒计时 | 点击芯片打开面板，再打卡 |
| 已过上班时间、未打卡 | 上班已逾期 + 逾期时长 | 点击芯片打开面板，再补卡 |
| 普通工作时段 | 下班倒计时 | 点击查看详情 |
| 午休前 30 分钟 | 距午休（可关闭智能切换） | 点击查看安排 |
| 午休期间 | 午休倒计时（距午休结束） | 点击查看安排 |
| 下班前 10 分钟 | 下班倒计时 + 柔和高亮 | 不闪烁 |
| 到点但未下班打卡 | 待下班打卡 + 加班计时 | 点击芯片，在面板中下班打卡 |
| 实际下班打卡后 | 已下班 + 今日实际工时 | 点击查看打卡与加班详情 |
| 到点仍无上班打卡 | 今日缺卡 | 点击芯片打开面板补卡 |
| 休息日 | 今日休息 | 可设置休息日隐藏 |

- **原生交互**：与上下文占用圆环一致，悬浮 200ms 只显示提示；点击芯片展开/收起面板，点击外部或按 Esc 关闭；面板顶部锚定并自动避免超出视口
- **今日概览**：点击面板顶部显示上班打卡时间、实时/最终工时、下班打卡时间、加班时长和当天时间安排；原有时间设置保留在下方
- **实际下班打卡**：打卡按钮只放在点击面板中，避免误触；未到或已到下班时间都可打卡，实际工时按下班打卡时刻定格；可重复下班打卡，以最后一次时间为准并重新计算工时、加班
- **准确工时与圆环**：工时从实际上班打卡算起，仅扣除与打卡区间真实重叠的午休；圆环在午休中暂停，午休结束不会倒退，下班时恰好走满
- **独立提醒**：上班截止前 5 分钟/1 分钟及逾期提醒保留；午休开始、午休结束、下班前提醒各有开关，新增提醒默认关闭
- **本地持久化**：设置和每日打卡记录保存在浏览器 `localStorage`，重启不丢
- **固定最右侧**：芯片显示在上下文占用圆环和百分比之后；同时兼容宿主插槽排序与底栏 Flex 视觉排序
- **原生明亮/暗黑主题**：触发器、14px 圆环、Tooltip 和面板复用宿主的菜单背景、交互底色、文字、边框与阴影 Token；跟随 DSH 主题切换，而非读取系统外观；界面语言中/英自动切换；尊重系统减少动态效果设置

## 安装

包为纯 JavaScript、无构建脚本，三种渠道任选其一（对应 DSH《打包与安装插件》规范）：

**① 本地目录 / git 克隆**（改源码即时生效）——在 DSH 会话中让 Agent 执行：

```text
plugin_manager install_bundle → <本仓库克隆路径>
```

**② tarball**（免构建授权，适合分发）：

```sh
pnpm pack                                  # 产出 attendance-clock-x.y.z.tgz
dsh plugin --profile <名称> add ./attendance-clock-x.y.z.tgz
```

**③ GitHub 直装**：

```sh
dsh plugin --profile <名称> add github:hualiyexi/attendance-clock
```

## 兼容性

manifest 声明 `engines.dsh: ">=0.2.0-0 <0.3.0-0"`：适配 DSH `0.2.x` 运行时（预发布版本也参与匹配）。版本不满足时安装/启动会明确拒绝，不会带病加载。

## 配置

所有时间都在**点击展开的设置面板**中调整（点击芯片打开，再次点击、点击外部或按 Esc 关闭）：

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 上班时间 | 08:30 | 上班打卡截止；此前未打卡显示上班倒计时，点击芯片打卡 |
| 下班时间 | 17:30 | 计划下班时间；须晚于上班时间 |
| 午休模式 | 关 | 开启后可设置午休时间，并展开午休相关选项 |
| 午休开始 | 12:00 | 需早于午休结束 |
| 午休结束 | 13:30 | 午休期间倒计时到该时刻 |
| 午休前智能切换 | 开 | 午休前 30 分钟从下班倒计时切换为“距午休” |
| 午休开始前提醒 | 关 | 提前 5 分钟发送系统通知 |
| 午休结束前提醒 | 开 | 提前 5 分钟发送系统通知，保留旧版默认行为 |
| 下班前提醒 | 关 | 提前 5 分钟发送系统通知 |
| 休息日隐藏芯片 | 关 | 开启后周末不渲染芯片 |

修改立即生效，设置保存在本机浏览器的 `localStorage`：

- `dsw-att.settings`：时间与显示、提醒选项
- `dsw-att.YYYY-MM-DD`：当天上班打卡毫秒时间戳（沿用旧版记录）
- `dsw-att.out.YYYY-MM-DD`：当天最后一次下班打卡毫秒时间戳（重复打卡覆盖更新）

阈值常量：`RING_MS`（提醒前 5 分钟）、`SOON_MS`（上班前 1 分钟二次提醒）、`NEAR_END_MS`（下班前 10 分钟高亮）、`LUNCH_LEAD_MS`（午休前 30 分钟智能切换），在 `client.js` 顶部调整。

> 说明：这些是**浏览器端**参数，渲染在 Web 页面的 Client 模块不接收 cordis 行配置，因此没有做成插件 Config 字段——避免提供"可配置但不生效"的假选项；DSH 的配置规范（不同部署不同值的参数应走 Config）适用于 Host 侧插件。
